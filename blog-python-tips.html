10 Python Tips Every Data Scientist Should Know

December 28, 2024 4 min read By Abdullah Bin Zubair

Python is the backbone of data science, but mastering its nuances can significantly boost your productivity. Here are 10 essential tips that have transformed my workflow and can help you write cleaner, faster, and more efficient code.

1. List Comprehensions for Cleaner Code

Instead of using loops, list comprehensions provide a more Pythonic and faster way to create lists: 

# Instead of this:
squares = []
for i in range(10):
    squares.append(i**2)

# Do this:
squares = [i**2 for i in range(10)]

2. Use enumerate() for Index and Value

When you need both the index and value while iterating, enumerate() is your friend: 

# Instead of this:
for i in range(len(my_list)):
    print(f"Index {i}: {my_list[i]}")

# Do this:
for i, value in enumerate(my_list):
    print(f"Index {i}: {value}")

3. F-strings for String Formatting

F-strings (formatted string literals) are faster and more readable than older formatting methods: 

name = "Abdullah"
age = 22

# Modern way:
message = f"My name is {name} and I'm {age} years old"

# You can even do inline calculations:
print(f"Next year I'll be {age + 1}")

4. Use .get() for Dictionaries

Avoid KeyError exceptions by using the .get() method with a default value: 

# Instead of this (risky):
value = my_dict['key']

# Do this (safe):
value = my_dict.get('key', 'default_value')

5. Zip for Parallel Iteration

When you need to iterate over multiple lists simultaneously, zip() is incredibly useful: 

names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]

for name, age in zip(names, ages):
    print(f"{name} is {age} years old")

6. Use Sets for Unique Elements and Fast Lookups

Sets provide O(1) lookup time and automatically handle duplicates: 

# Remove duplicates:
my_list = [1, 2, 2, 3, 4, 4, 5]
unique_values = list(set(my_list))

# Fast membership testing:
allowed_users = {'alice', 'bob', 'charlie'}
if user in allowed_users:  # This is very fast!
    grant_access()

7. Context Managers with 'with'

Always use context managers for file operations to ensure proper cleanup: 

# Instead of this:
file = open('data.txt', 'r')
content = file.read()
file.close()

# Do this (automatic cleanup):
with open('data.txt', 'r') as file:
    content = file.read()

8. Use defaultdict for Counting and Grouping

defaultdict from collections eliminates the need to check if keys exist: 

from collections import defaultdict

# Counting occurrences:
counts = defaultdict(int)
for item in data:
    counts[item] += 1

# Grouping items:
groups = defaultdict(list)
for item in data:
    groups[item.category].append(item)

9. Generator Expressions for Memory Efficiency

When working with large datasets, use generators instead of lists to save memory: 

# List comprehension (stores all in memory):
squares_list = [x**2 for x in range(1000000)]

# Generator expression (computes on-the-fly):
squares_gen = (x**2 for x in range(1000000))

# Use with functions that accept iterables:
total = sum(x**2 for x in range(1000000))

10. Use pandas .apply() with Lambda Functions

Combine pandas with lambda functions for quick data transformations: 

import pandas as pd

# Apply function to column:
df['price_usd'] = df['price_eur'].apply(lambda x: x * 1.1)

# Apply to multiple columns:
df['full_name'] = df.apply(lambda row: f"{row['first_name']} {row['last_name']}", axis=1)

Bonus Tip: Use Type Hints

Type hints make your code more readable and help catch bugs early: 

def calculate_average(numbers: list[float]) -> float:
    """Calculate the average of a list of numbers."""
    return sum(numbers) / len(numbers)

# Modern Python also supports:
from typing import Optional

def find_user(user_id: int) -> Optional[dict]:
    # Returns dict if found, None otherwise
    return users.get(user_id)

Conclusion

These tips represent just the tip of the iceberg when it comes to Python best practices. The key is to:

  • Write code that's readable first, then optimize for performance
  • Leverage Python's built-in functions and standard library
  • Use appropriate data structures for your use case
  • Practice regularly and learn from others' code

Remember, the goal isn't to use every trick in every project, but to know when each technique is most appropriate. Happy coding!
